منصة معرفية وثقافية متخصصة في اللغة والترجمة الكردية والتاريخ والثقافة الكردية في شمال وشرق سوريا. تهدف المنصة إلى جمع وتوثيق وترجمة المحتوى الكردي، والتعريف بالتاريخ والتراث والأدب والفنون والعادات والتقاليد والمصطلحات والوثائق والشخصيات والأحداث المرتبطة بالمنطقة.

تشمل المنصة محتوى متنوعًا حول اللغة الكردية ولهجاتها، الترجمة الكردية، الأدب والشعر، التاريخ الكردي، التراث الشعبي، الجغرافيا، الثقافة، الإعلام، الوثائق والمصادر التاريخية، مع التركيز على حفظ الذاكرة الثقافية وإتاحة المعرفة للأجيال القادمة.

مشروع مفتوح للمعرفة والتوثيق والترجمة، يجمع كل ما يتعلق بكرد شمال وشرق سوريا وتراثهم ولغتهم وتاريخهم وثقافتهم.
